
# Remote Server Restart and Service Validation

## 1. Project Overview

Developed PowerShell automation to restart remote computers and capture service status before and after reboot.

## 2. Objective

Support controlled remote server restart activities and post-reboot service validation.

## 3. Scope of Automation

- Remote computer restart.
- Capture service status before reboot.
- Execute remote restart.
- Capture service status after reboot.
- Validate service recovery.

## 4. Technologies Used

- PowerShell
- Windows Server
- Remote computer administration
- Windows Services

## 5. Implementation

The solution automated remote computer restarts and captured service status before and after reboot to support post-maintenance verification.

The actual remote execution method, waiting period and recovery checks should be documented based on the original script.

## 6. Validation

- Verify remote computer connectivity.
- Capture pre-restart service status.
- Verify that the restart operation was initiated.
- Confirm that the server becomes reachable again.
- Compare service status before and after reboot.

## 7. Operational Considerations

- Obtain appropriate change approval.
- Notify affected users where required.
- Confirm maintenance windows.
- Validate critical services after restart.

## 8. Project Outcome

Improved post-maintenance verification and support for remote server restart activities.
